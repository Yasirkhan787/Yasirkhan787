### 🏗️ Featured System Architecture: Waste Transport Management System (WTMS)

An end-to-end distributed microservice ecosystem engineered for real-time fleet telemetry, spatial route optimization, and asynchronous event processing:
* **Event-Driven & Real-Time Pipeline:** Decoupled inter-service communication via **Apache Kafka** and **RabbitMQ**, paired with **WebSockets** for live sub-second vehicle tracking.
* **Spatial & Low-Latency Persistence:** Powered by **PostgreSQL + PostGIS** for geofencing and route computation, **Redis** for distributed caching, and **OpenSearch** for fast indexing.
* **Resilience & Gateway Security:** Centralized **Spring Security (JWT/OAuth2 & RBAC)** at the API Gateway with **Resilience4j** circuit breakers, rate limiters, and retries across **Dockerized** nodes.
